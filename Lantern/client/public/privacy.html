プライバシーポリシー

Lantern（以下「本アプリ」）における個人情報の取り扱いについて定めます。

最終更新日: 2026年8月6日 提供者: Pillow-Hiro

1. この文書の考え方

本アプリは、利用者が自分の言葉を記録するための道具です。 記録は利用者のものであり、提供者のものではありません。

そのため、この文書は「何を集めているか」ではなく 「何がどこに置かれ、誰が見られるか」を書きます。 利用者が自分で判断できることが目的です。

3. 写真の扱い

写真は端末の中だけに保存され、提供者のサーバーには送信されません。

  • 記録に添えた写真は、端末のアプリ領域に保存されます
  • 提供者はその写真を見ることができません
  • 端末を変更した場合、写真は移りません
  • Web版では写真機能を提供していません
  • 写真がAIに渡されることはありません

4. 記録した文章の扱い

記録した文章は、以下の2か所に渡ります。

4-1. データベース（Supabase）

記録は Supabase（Supabase Inc.）のデータベースに保存されます。 サーバーは日本国外に置かれる場合があります。

この保存領域は、提供者が管理者として閲覧できる状態にあります。 提供者が個人の記録を読む意図はありませんが、 技術的に読めない仕組みにはなっていません。この点を明示します。

4-2. AI（Anthropic Claude API）

以下の場合に、記録した文章が Anthropic PBC の API に送信されます。

いつ送るもの
記録を保存したときその日の記録と、直近の記録
「今日の灯り」を表示するとき前日の記録のみ
「今週・今月の振り返り」を押したときその期間の記録
「過去との対話」を押したとき対象期間と当日の記録
キーワードを表示するとき対象期間の記録
動画・配信の観察を押したとき記録と、公開されている動画・配信の情報

ボタンを押していないときにAIが動くことはありません。 定期実行も行いません。

写真をAIに送ることはありません。

Anthropic の取り扱いについては Anthropic のプライバシーポリシーをご確認ください。

5-1. 保管される場所（国外への移転）

上記のサービスはいずれも日本国外（主に米国）にサーバーを置いています。 本アプリを利用すると、記録・アイデア・メールアドレスは、 これらのサービスを通じて国外のサーバーに保管されます。

各国の個人情報の保護に関する制度は日本と同一ではありません。 各サービスの取り扱いは、それぞれのプライバシーポリシーをご確認ください。

5-2. Google / YouTube の連携について

YouTube との連携を選んだ場合、本アプリは YouTube API Services を利用します。 利用にあたっては YouTube 利用規約 および Google プライバシーポリシー が適用されます。

本アプリが受け取るのは、チャンネル名・動画のタイトルと公開日・再生回数などの 公開されている統計情報と、連携に必要な認可情報です。 視聴履歴・登録チャンネルの一覧・コメントの内容は取得しません。

本アプリへのアクセス権は、アプリ内の「分析」から解除できるほか、 Google アカウントのセキュリティ設定 からいつでも取り消せます。

6. 保存期間と削除

利用者はいつでも自分で消すことができます。

操作場所消えるもの
記録の削除記録の詳細その日の記録
アカウントの削除設定記録・アイデア・連携・アカウントのすべて

アカウントを削除すると、提供者側にデータは残りません。 元に戻すことはできません。 必要な記録は、設定の「データのエクスポート」で JSON として手元に保存できます。

端末の中の写真は、アカウント削除では消えません。 端末側で削除するか、アプリを削除してください。

7. 連携の解除

YouTube / Twitch の連携は、ダッシュボードからいつでも解除できます。 解除すると、保存していたアクセストークンは削除されます。

なお、Twitch の過去配信は Twitch 側で一定期間後に消えるため、 取得できた時点の情報を本アプリ内に保存しています。 連携を解除しても、この記録は残ります。 不要な場合はアカウントの削除を行ってください。

8. 未成年の利用について

13歳未満を対象としたサービスではありません。

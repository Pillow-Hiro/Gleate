# 利用規約

Lantern（以下「本アプリ」）の利用条件を定めます。

最終更新日: 2026年8月16日
提供者: Pillow-Hiro

---

## 1. この文書の考え方

本アプリは、利用者が自分の言葉を記録するための道具です。
**記録は利用者のものであり、提供者のものではありません。**

そのため、この規約は「提供者を守るための取り決め」を並べる前に、
**利用者の記録がどう扱われるかを先に書きます**（第4条）。

本規約に同意いただけない場合、本アプリは利用できません。

---

## 2. 定義

| 語 | 意味 |
|---|---|
| 本アプリ | Lantern（iOS アプリおよび Web 版） |
| 利用者 | 本アプリを利用する個人 |
| 記録 | 利用者が本アプリに入力した文章・写真・添付ファイル・アイデア |
| 有料プラン | 第6条に定める月額または年額の継続課金 |
| 無料の範囲 | 有料プランに加入していない利用者が使える機能 |

---

## 3. アカウント

利用にはメールアドレスとパスワードによる登録が必要です。

- 登録した情報は、利用者自身が管理してください
- パスワードの管理不十分による損害の責任は負いかねます
- 1人が複数のアカウントを作ることを禁じてはいませんが、
  無料の範囲を複数アカウントで回避する行為は第8条の禁止事項にあたります
- **アカウントはいつでも削除できます。** 削除すると記録も消え、元に戻せません

---

## 4. 記録の権利

**記録の著作権は利用者に帰属します。**

提供者は、本アプリを動かすために必要な範囲でのみ記録を扱います。
具体的には次のとおりです。

- **AI の学習には使いません。** 提供者が記録を学習データとして利用することも、
  第三者に学習目的で提供することもありません
- **提供者は記録を閲覧しません。** ただし、障害の調査のために
  データベースへ技術的にアクセスできる状態にはあります
  （詳細はプライバシーポリシー）
- **写真と添付ファイルは端末の中だけに置かれます。**
  サーバーには送られません。端末を変えると引き継げません
- 記録は、AI が応答を作るために Anthropic 社の API へ送られます。
  Anthropic 社は API 経由のデータを学習に利用しないと表明しています

**利用者は、いつでも記録をエクスポートできます。**
この機能を有料にすることはありません。

## 5. AI が生成する文章について

本アプリは、記録に対して AI が生成した文章を表示します。

- **これは助言ではありません。** 判断は利用者自身が行うものです
- **医療・法律・金融・その他の専門的な助言ではありません。**
  該当する事柄については、資格を持つ専門家にご相談ください
- AI の生成する文章は誤りを含むことがあります。事実として扱わないでください
- 生成された文章の内容について、提供者は責任を負いかねます

## 6. 有料プラン

### 6.1 無料の範囲

次の機能は、有料プランに加入しなくても利用できます。
**これらを有料に移すことはありません。**

- 記録・アイデアの作成、閲覧、編集、削除
- 写真と添付ファイル
- 検索
- **記録のエクスポート**
- アカウントの削除
- 記録を書いたときの AI の応答（1日1回）
- 今日の灯り（1日1回）
- 今週の発見（週1回）

### 6.2 有料プランで使える機能

- 月次の振り返り
- 過去との対話
- 頻出キーワードの分析
- YouTube / Twitch との連携と、その分析
- AI の利用回数の上限の引き上げ

### 6.3 料金と支払い

| | |
|---|---|
| 月額プラン | 【価格】（税込） |
| 年額プラン | 【価格】（税込） |
| 支払方法 | Apple App Store を通じた決済 |
| 支払時期 | 購入時、および更新日ごと |

**支払いは Apple App Store を通じて行われます。**
提供者が利用者のクレジットカード情報を受け取ることはありません。
決済に関しては Apple の定める条件が適用されます。

### 6.4 自動更新と解約

- 有料プランは**自動更新**です。期間終了の24時間前までに解約しない限り、
  同じ期間で自動的に更新され、その時点の料金が請求されます
- **解約は端末の「設定 > Apple ID > サブスクリプション」から行います。**
  本アプリ内で解約手続きを完結させることはできません（Apple の仕組みによります）
- 解約しても、支払い済みの期間の終わりまでは有料プランを利用できます

### 6.5 返金

デジタルコンテンツの性質上、提供者からの返金は行いません。
返金の請求は Apple のポリシーに従い、Apple に対して行ってください。

### 6.6 料金の変更

料金を変更する場合は、変更の30日前までにアプリ内で告知します。
値上げの場合、既に加入している方は、更新のタイミングで
Apple から同意の確認が行われます。同意しない場合は更新されません。

## 7. サービスの変更・中断・終了

- 機能の追加・変更・削除を行うことがあります
- 障害・保守・外部サービスの停止により、利用できない時間が生じることがあります
- 本アプリの提供を終了する場合は、**90日前までに告知**し、
  記録をエクスポートできる期間を設けます。有料プランの未経過分は日割りで返金します

## 8. 禁止事項

次の行為を禁じます。

- 法令または公序良俗に反する行為
- 本アプリのサーバー・API に対する、通常の利用を超える負荷をかける行為
- 認証を回避する行為、他人のアカウントへアクセスする行為
- 本アプリを解析・改変して、有料プランの制限を回避する行為
- 無料の範囲を超えるために複数のアカウントを作る行為
- 他人の権利を侵害する記録を保存する行為
- 本アプリを通じて第三者に有害なものを送信する行為

違反があった場合、事前の通知なくアカウントを停止することがあります。

## 9. 免責

- 本アプリは現状のまま提供されます。特定の目的への適合性を保証しません
- 記録の消失について、提供者は責任を負いかねます。
  大切な記録は**エクスポートして手元にも保管**してください
- 提供者の責任は、故意または重過失による場合を除き、
  **利用者が直近12か月に支払った金額を上限**とします
- 消費者契約法により、この制限が適用されない場合があります

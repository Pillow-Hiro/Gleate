# Lantern について

**Lantern は、創作を続ける人のための記録アプリです。**

書いたことを、誰かに見せるために整える必要がない場所。
評価されず、励まされず、ただ言葉が積み重なっていきます。

iPhone と iPad で使えます。App Store で配信しています。

---

## 何をするアプリか

1日にひとつ、その日のことを記録します。

- **やったこと**を1行残す
- 必要なら**よかったこと・困ったこと・次にやること**を足す
- 写真とファイルを添える（**端末の中だけに保存されます**）
- カレンダーと検索で読み返す

書くことが浮かばない日のために、問いが50通り用意されています。

## 灯りは、外から来るのではない

Lantern という名前は「自らを灯明とし、自らを拠り所とせよ」から
取りました。答えを与えるアプリではありません。

**Lantern の応答は、評価しません。褒めません。励ましません。**
「頑張っていますね」「成長しましたね」とは言いません。
することは2つだけです。記録を並べること。変化を示すこと。
そこに意味を与えるのは、書いた本人だけです。

## YouTube / Twitch との連携について

**任意の機能です。** 連携しなくても、記録に関するすべての機能を
ご利用いただけます。

連携すると、投稿した動画や配信の記録を、日々の記録と同じ画面に
並べられます。**創作の内側（書いたこと）と外側（届いたこと）を、
ひとつの場所で読み返すため**の機能です。

Lantern が読み取るのは、ご自身のチャンネルの公開情報だけです
（動画の題名、公開日、再生数など）。**投稿・編集・削除は行いません。**
取得した情報は、その画面に表示し、記録と並べる目的にのみ使います。
第三者への提供・販売・広告への利用は行いません。

Google からの情報の取り扱いは
[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)
（Limited Use を含む）に従います。詳細は
[プライバシーポリシー](/privacy.html)に記載しています。

## 料金

記録・写真・アイデア・検索・書き出し、今日の灯りと今週の発見は
**無料**です。

月ごとの振り返り、過去との対話、頻出キーワード、配信や動画の
読み解きは **Lantern Plus**（月額800円／年額8,000円）でご利用
いただけます。月額・年額とも、最初の2週間は無料でお試しいただけます。

**書いたものの持ち出し（エクスポート）は、ずっと無料です。**
記録が利用者のものである、という前提と衝突するためです。

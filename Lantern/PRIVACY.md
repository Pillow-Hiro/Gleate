# プライバシーポリシー

Lantern（以下「本アプリ」）における個人情報の取り扱いについて定めます。

最終更新日: 2026年8月6日
提供者: Pillow-Hiro

---

## 1. この文書の考え方

本アプリは、利用者が自分の言葉を記録するための道具です。
記録は利用者のものであり、提供者のものではありません。

**そのため、この文書は「何を集めているか」ではなく
「何がどこに置かれ、誰が見られるか」を書きます。**
利用者が自分で判断できることが目的です。

---

## 2. 取得する情報

| 情報 | 取得の理由 | 必須か |
|---|---|---|
| メールアドレス | ログインのため | 必須 |
| パスワード | 同上 | 必須 |
| 記録した文章（やったこと・よかったこと・困ったこと・次にやること） | 記録の保存と振り返りのため | 利用者が書いたときのみ |
| アイデアとして書いた文章 | 同上 | 同上 |
| 記録した日付 | 一覧とカレンダーのため | 記録に伴い自動 |
| YouTube / Twitch のアクセストークンと公開情報 | 連携を選んだ場合のみ | 任意 |
| 購入と購読の状態 | 有料プランの管理のため | 購入した場合のみ |

**取得しないもの**

- 位置情報
- 連絡先
- 端末の識別子を用いた広告目的の情報
- 利用状況の分析データ（どの画面を開いたか等の記録は行いません）

本アプリに広告はありません。第三者への販売・提供も行いません。

---

## 3. 写真の扱い

**写真は端末の中だけに保存され、提供者のサーバーには送信されません。**

- 記録に添えた写真は、端末のアプリ領域に保存されます
- 提供者はその写真を見ることができません
- 端末を変更した場合、写真は移りません
- Web版では写真機能を提供していません
- 写真がAIに渡されることはありません

---

## 4. 記録した文章の扱い

**記録した文章は、以下の2か所に渡ります。**

### 4-1. データベース（Supabase）

記録は Supabase（Supabase Inc.）のデータベースに保存されます。
サーバーは日本国外に置かれる場合があります。

**この保存領域は、提供者が管理者として閲覧できる状態にあります。**
提供者が個人の記録を読む意図はありませんが、
技術的に読めない仕組みにはなっていません。この点を明示します。

### 4-2. AI（Anthropic Claude API）

以下の場合に、記録した文章が Anthropic PBC の API に送信されます。

| いつ | 送るもの |
|---|---|
| 記録を保存したとき | その日の記録と、直近の記録 |
| 「今日の灯り」を表示するとき | 前日の記録のみ |
| 「今週・今月の振り返り」を押したとき | その期間の記録 |
| 「過去との対話」を押したとき | 対象期間と当日の記録 |
| キーワードを表示するとき | 対象期間の記録 |
| 動画・配信の観察を押したとき | 記録と、公開されている動画・配信の情報 |

ボタンを押していないときにAIが動くことはありません。
定期実行も行いません。

**写真をAIに送ることはありません。**

Anthropic の取り扱いについては
[Anthropic のプライバシーポリシー](https://www.anthropic.com/legal/privacy)をご確認ください。

---

## 4-3. 購入と購読の状態（RevenueCat）

有料プランに加入された場合、**購入と購読の状態**が
RevenueCat, Inc. のサーバーに送られ、そこで管理されます。
本アプリはこの仕組みを使って、有料機能を開くかどうかを判定します。

送られるのは購入と購読に関する情報だけです。
**記録した文章は送られません。**

支払いそのものは Apple が処理します。**クレジットカード番号などの
決済情報を、提供者も RevenueCat も受け取りません。**

## 5. 外部サービス

本アプリは以下を利用します。

| サービス | 用途 | 渡るもの |
|---|---|---|
| Supabase | 認証・データベース | メールアドレス・記録・アイデア |
| Resend | 認証メールの送信 | メールアドレス（**記録の中身は渡しません**） |
| Anthropic | AIの応答 | 記録した文章（上記4-2の場合） |
| Render | サーバーの実行 | 通信のログ（記録の中身は含みません） |
| Vercel | Web版の配信 | アクセスの技術的情報 |
| RevenueCat | 購読の管理 | 購入と購読の状態、匿名の利用者ID |
| Unsplash | 起動画面の背景写真 | 利用者の情報は渡しません。撮影者名を起動画面に表示します |
| Google / YouTube | 連携を選んだ場合のみ | 認可の情報 |
| Twitch | 同上 | 同上 |

サーバーのログには、記録の中身・利用者の識別子・認証情報を
出力しない設計としています。

### 5-1. 保管される場所（国外への移転）

上記のサービスはいずれも**日本国外（主に米国）にサーバーを置いています**。
本アプリを利用すると、記録・アイデア・メールアドレスは、
これらのサービスを通じて国外のサーバーに保管されます。

各国の個人情報の保護に関する制度は日本と同一ではありません。
各サービスの取り扱いは、それぞれのプライバシーポリシーをご確認ください。

| サービス | 主な所在 | 取り扱い |
|---|---|---|
| Supabase | 米国 | [プライバシーポリシー](https://supabase.com/privacy) |
| Resend | 米国 | [プライバシーポリシー](https://resend.com/legal/privacy-policy) |
| Anthropic | 米国 | [プライバシーポリシー](https://www.anthropic.com/legal/privacy) |
| Render | 米国 | [プライバシーポリシー](https://render.com/privacy) |
| Vercel | 米国 | [プライバシーポリシー](https://vercel.com/legal/privacy-policy) |
| RevenueCat | 米国 | [プライバシーポリシー](https://www.revenuecat.com/privacy) |

### 5-2. Google / YouTube の連携について

YouTube との連携を選んだ場合、本アプリは **YouTube API Services** を利用します。
利用にあたっては [YouTube 利用規約](https://www.youtube.com/t/terms) および
[Google プライバシーポリシー](https://policies.google.com/privacy) が適用されます。

本アプリが受け取るのは、チャンネル名・動画のタイトルと公開日・再生回数などの
**公開されている統計情報**と、連携に必要な認可情報です。
視聴履歴・登録チャンネルの一覧・コメントの内容は取得しません。

本アプリへのアクセス権は、アプリ内の「分析」から解除できるほか、
[Google アカウントのセキュリティ設定](https://myaccount.google.com/permissions)
からいつでも取り消せます。

## 6. 保存期間と削除

**利用者はいつでも自分で消すことができます。**

| 操作 | 場所 | 消えるもの |
|---|---|---|
| 記録の削除 | 記録の詳細 | その日の記録 |
| アカウントの削除 | 設定 | 記録・アイデア・連携・アカウントのすべて |

アカウントを削除すると、提供者側にデータは残りません。
**元に戻すことはできません。**
必要な記録は、設定の「記録を書き出す」で手元に保存できます。
本文（JSON と Markdown）に加えて、**端末の中の写真と添付も同梱されます。**
保存先は利用者が選びます（iCloud Drive などを選べます）。
**自動で外部へ送る機能はありません。**

端末の中の写真は、アカウント削除では消えません。
端末側で削除するか、アプリを削除してください。
**削除の前に書き出しておけば、写真も一緒に残せます。**

---

## 7. 連携の解除

YouTube / Twitch の連携は、ダッシュボードからいつでも解除できます。
解除すると、保存していたアクセストークンは削除されます。

なお、Twitch の過去配信は Twitch 側で一定期間後に消えるため、
取得できた時点の情報を本アプリ内に保存しています。
**連携を解除しても、この記録は残ります。**
不要な場合はアカウントの削除を行ってください。
